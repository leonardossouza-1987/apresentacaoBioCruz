# ApresentacaoBioCruz

Apresentacao e roteiro do projeto **Biocruz — Analise de Dados & Inteligencia Estrategica**, desenvolvido como Projeto Integrador do curso de Programador Front-End.

## Arquivos

- `apresentacao.html` — Apresentacao em 25 slides com design system do site
- `roteiro.html` — Roteiro de fala em 2 modos (crianca de 7 anos e estudante de programacao)

## Tecnologias

- HTML5 semantico
- CSS3 (variaveis, grid, transicoes)
- JavaScript vanilla (navegacao por teclado, swipe, persistencia)
- Google Fonts (Inter)

## Como executar

```bash
cd ~/apresentacaoBioCruz
python3 -m http.server 8002
```

Acesse:

- http://localhost:8002/apresentacao.html
- http://localhost:8002/roteiro.html

## Navegacao da apresentacao

| Acao | Como |
|---|---|
| Proximo slide | Clique, seta direita, espaco ou botao > |
| Slide anterior | Seta esquerda ou botao < |
| Primeiro / ultimo | Home / End |
| Swipe | Arraste horizontal em mobile |
| Imprimir / PDF | Botao no canto inferior esquerdo |
